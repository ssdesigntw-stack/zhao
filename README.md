# zhao
昭安宮農民曆

三重昭安宮李天池府千歲的線上農民曆。以網頁方式顯示農民曆 PDF，手機可「加入主畫面」當作 App 使用。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁程式（畫面、翻頁、縮放），一般不需要修改 |
| `calendar.json` | **每年要改的設定檔**：年份、PDF 檔名、上方按鈕與頁碼 |
| `zhao.pdf` | 農民曆 PDF |
| `manifest.json` | 加入主畫面時的 App 名稱、顏色、圖示 |
| `logo.jpg` | 主畫面圖示 |

## 功能

- **上方章節按鈕**：依 `calendar.json` 自動產生，點了跳到該章節；翻頁時會自動亮起目前所在的章節
- **翻頁**：
  - 「上一頁 / 下一頁」按鈕
  - 手指**往右滑 → 下一頁**、往左滑 → 上一頁
  - 電腦可用鍵盤左右鍵
- **縮放**：兩指縮放（最多 4 倍）、雙擊放大 / 還原，放大後可單指拖曳
- **上下捲動**：未放大時，手指在頁面上可上下捲動網頁
- **速度**：只下載正在看的頁面，並在背景預先準備上一頁、下一頁
- **網路不穩**：載入較久時顯示「載入中…」，失敗時顯示「點此重試」
- **加入主畫面**：可當 App 使用；更新內容後，已加入主畫面的使用者**不需要重新加入**

## 每年更換年份

**只需要換 PDF、改 `calendar.json`，不用改 `index.html`。**

### 步驟

1. 把新年度的 PDF 放進資料夾
   - 可以沿用檔名 `zhao.pdf` 直接覆蓋，或用新檔名（例如 `zhao-2027.pdf`）
2. 打開 `calendar.json`，修改：
   - `year`：新年份，例如 `2027`
   - `pdf`：PDF 檔名
   - `version`：改成新的值（例如 `"2027"`）。**沿用相同 PDF 檔名時一定要改**，否則使用者手機可能還顯示舊的 PDF
   - `sections`：照新 PDF 的版面，修改每個按鈕的 `page` 頁碼
3. 上傳到網站，用手機打開確認每個按鈕都跳到正確的頁面

### calendar.json 範例

```json
{
  "year": 2027,
  "pdf": "zhao.pdf",
  "version": "2027",
  "sections": [
    { "label": "昭安宮簡介",       "page": 1 },
    { "label": "點光明燈",         "page": 12 },
    { "label": "太歲{ganzhi}年",   "page": 18 },
    { "label": "{year}/1-3月",     "page": 20 },
    { "label": "{nextYear}/1-2月", "page": 44 }
  ]
}
```

### 按鈕文字可用的代號

按鈕文字裡的代號會依 `year` 自動換算，年份相關的文字不用每年手動改：

| 代號 | 說明 | 2027 年時顯示 |
|---|---|---|
| `{year}` | 當年 | 2027 |
| `{nextYear}` | 隔年 | 2028 |
| `{prevYear}` | 前一年 | 2026 |
| `{ganzhi}` | 干支 | 丁未 |
| `{zodiac}` | 生肖 | 羊 |

例如 `太歲{ganzhi}年` 會顯示「太歲丁未年」，`{year}/1-3月` 會顯示「2027/1-3月」。

### 注意事項

- `page` 是 **PDF 的頁碼**（PDF 閱讀器顯示的第幾頁），不是農民曆印在紙上的頁碼
- 按鈕會依頁碼由小到大排列；要增減按鈕，直接在 `sections` 加一行或刪一行即可
- 頁碼超過 PDF 總頁數、或少寫文字 / 頁碼的那一行會被略過，不會讓整個網頁壞掉
- `calendar.json` 是 JSON 格式：文字要用雙引號、每行之間用逗號隔開、**最後一行後面不能有逗號**。改完可以貼到 [JSON 驗證工具](https://jsonlint.com/) 檢查

## 本機測試

`calendar.json` 和 PDF 需要透過網站讀取，**直接雙擊 `index.html` 會打不開**，要先架一個本機伺服器：

```
cd C:\SSD\zhao-work
npx http-server -c-1
```

- `-c-1` 是關閉暫存，確保每次都讀到最新檔案
- 電腦開啟：`http://127.0.0.1:8080/zhao/`
- 手機（連同一個 Wi-Fi）開啟：`http://電腦的IP:8080/zhao/`，IP 會顯示在執行 npx 的視窗上
- 結束測試：在 npx 視窗按 `Ctrl + C`

## 技術備註

- 使用 [pdf.js](https://mozilla.github.io/pdf.js/) 5.4（從 jsDelivr CDN 載入）顯示 PDF
- 目前 PDF 的掃描圖是 JPEG 2000 格式，解碼較慢。若印刷廠可以把 PDF 圖片改用一般 **JPEG** 壓縮匯出，載入會更快、檔案也更小
- 需要 iOS 16.4 以上或近期版本的 Android Chrome
